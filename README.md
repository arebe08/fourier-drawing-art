# 푸리에 드로잉 참여형 학습 프로그램

학생이 목표 그림을 선택하고, 프로그램이 미리 계산한 푸리에 성분의
주파수와 위상은 고정한 채 각 원의 반지름(진폭)을 직접 추정하는 Streamlit 앱입니다.

## 파일
- `app.py`: 메인 Streamlit 프로그램
- `requirements.txt`: Python 의존성

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## GitHub + Streamlit Community Cloud 배포

1. GitHub에서 새 저장소(repository)를 만듭니다.
2. `app.py`, `requirements.txt`를 저장소 루트에 업로드합니다.
3. Streamlit Community Cloud에 GitHub 계정으로 로그인합니다.
4. 새 앱 배포에서 해당 저장소와 `app.py`를 선택합니다.
5. Deploy를 누릅니다.

## 프로그램 흐름

1. 목표 그림 선택
2. 사용할 원의 개수 확인
3. 각 원의 반지름 입력
4. 목표 그림과의 유사도 확인
5. "더 크게 / 더 작게 / 적절함" 방향 힌트 확인
6. 값을 수정해 반복
7. 원하는 정확도에 도달
8. Plotly 에피사이클 애니메이션으로 회전 운동의 합 관찰
9. 위상을 무작위로 바꾸어 같은 반지름에서도 결과가 달라지는지 비교

## 수학적 설계

폐곡선을 복소수 함수 `z(t) = x(t) + i y(t)`로 보고 이산 푸리에 변환으로 계수를 구합니다.
각 복소 푸리에 계수는 다음 세 정보를 가집니다.

- 반지름: 계수의 절댓값(진폭)
- 회전속도: 주파수
- 시작각: 계수의 편각(위상)

학습자가 한 번에 세 요소를 모두 맞히는 것은 난도가 지나치게 높으므로,
이 앱에서는 목표 그림에서 계산한 주파수와 위상을 고정하고 반지름만 조절하도록 구성했습니다.
